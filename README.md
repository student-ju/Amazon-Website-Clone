# 🛒 Amazon UI Clone - Responsive E-Commerce Interface

A high-fidelity front-end clone of the Amazon homepage, built to demonstrate expertise in complex CSS layouts, multi-layered navigation, and scalable web architecture.

## 🚀 Live Demo
[View the Clone here](https://student-ju.github.io/Amazon-Website-Clone/)

## 🛠️ Engineering Breakdown

### **Complex UI Architecture**
- **Multi-Level Navigation:** Replicated the Amazon "Mega Menu" and sub-navigation bars using structured HTML5 and hover-state logic.
- **Hero Slider Implementation:** Developed a responsive hero section with layering techniques to mimic the core Amazon shopping experience.
- **Product Grid System:** Utilized **CSS Grid** and **Flexbox** to create a responsive 4-column product layout that re-stacks seamlessly on smaller viewports.

### **CSS Precision**
- **Brand Fidelity:** Matched Amazon’s specific color palette, typography, and iconography to ensure a 1:1 visual match.
- **Interactive Elements:** Implemented custom CSS transitions for buttons, search bars, and product cards to enhance user engagement.

### **Optimization & Best Practices**
- **Image Handling:** Managed high-resolution product assets to ensure fast rendering and visual clarity.
- **Modular Code:** Organized CSS into logical sections (Header, Hero, Footer, Grid) for easier maintenance and scalability.

## ✨ Key Features
- **Responsive Navigation:** A fully functional mobile-friendly header.
- **Dynamic Product Cards:** Styled components including ratings, price formatting, and "Add to Cart" interactions.
- **Back-to-Top Logic:** Smooth navigation features for long-scroll pages.
